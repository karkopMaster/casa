APK del cliente final (por empresa): abre /cliente/, con el nombre y el logo (ícono) de la empresa.

Instalar (VPS):
  cd /tmp/casa && git pull origin claude/fervent-cori-cfc5h8
  bash crm/apk-cliente/instalar-apk-cliente.sh
  cd /home/ubuntu/isp-crm/backend
  sudo -u ubuntu npx tsc -p tsconfig.json --noEmit
  sudo -u ubuntu cp -a dist dist.pre-apkcliente
  sudo -u ubuntu npm run build && sudo -u ubuntu pm2 restart isp-crm-api
Descargar:  https://<slug>.148-113-203-154.sslip.io/descargar-app-cliente.apk   (desde el celular)

Deshacer:
  cp /home/ubuntu/backups/gen-apk.sh.pre-cliente-<fecha> /home/ubuntu/isp-crm/apkbase/gen-apk.sh
  cp /home/ubuntu/backups/index.ts.pre-apkcliente-<fecha> /home/ubuntu/isp-crm/backend/src/index.ts
  rm /home/ubuntu/isp-crm/backend/src/routes/apkPortal.routes.ts ; recompilar y reiniciar
